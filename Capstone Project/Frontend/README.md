# Capstone Project - Frontend

This is the frontend application for the Capstone Project. It handles the user interface, routing, and interactions with the backend API.

## Features
- Interactive User Interface
- Integration with Backend APIs
- Responsive Design

## Prerequisites
- Node.js installed

## Setup and Execution
1. Open a terminal and navigate to this directory.
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
   *(Or use `npm start` depending on the framework configuration in `package.json`)*

4. The application should now be accessible in your web browser.
