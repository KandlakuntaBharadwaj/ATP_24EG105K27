# Capstone Project

This directory contains the Capstone Project, which is a full-stack application.

## Structure
The project is divided into two main parts:
- **[Frontend](./Frontend)**: The user interface of the application, built with modern frontend technologies.
- **[Backend](./Backend)**: The server-side logic, API endpoints, and database interactions.

## Getting Started
To run the full project locally, you will need to start both the Frontend and the Backend servers. Please refer to the respective `README.md` files inside the `Frontend` and `Backend` directories for detailed setup and execution instructions.
