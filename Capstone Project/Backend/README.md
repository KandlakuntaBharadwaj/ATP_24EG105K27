# Capstone Project - Backend

This is the backend service for the Capstone Project. It provides RESTful APIs, handles business logic, and manages database interactions.

## Features
- REST API Endpoints
- Database Integration
- File Uploads (e.g., Cloudinary)
- Authentication and Authorization

## Prerequisites
- Node.js installed
- Required environment variables configured (e.g., database URI, API keys)

## Setup and Execution
1. Open a terminal and navigate to this directory.
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the root of the Backend directory and add your environment variables.
4. Start the server:
   ```bash
   node index.js
   ```
   *(Or `npm start` / `npm run dev` if defined in `package.json`)*

5. The server will start running on the specified port.
